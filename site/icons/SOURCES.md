# Icon sources

The GitHub mark in both pages' footers is the 24 px `mark-github` icon from
GitHub's Octicons, under the MIT License. Its path is inlined unmodified into
`site/index.html` and `site/methods.html` as an `<svg>`, so no icon file ships;
`LICENSE-octicons.txt` is the Octicons licence, stored exactly as downloaded.

Both were fetched on 2026-10-09 from primer/octicons `main` at commit
`97825f832c98f817867f770d084c08e3edc6f78c`:

- Icon: https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-24.svg
- Licence: https://raw.githubusercontent.com/primer/octicons/main/LICENSE
